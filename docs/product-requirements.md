# Sway / 言和产品文档

## 1. 产品定位

Sway（言和）是一款高情商聊天输入法与表达增强工具。它帮助用户在聊天时把原本生硬、尴尬、没分寸或不知道怎么接的话，改写成更自然、更温柔、更幽默、更真诚的表达。

产品不是“代聊机器人”，核心价值是降低回复压力，给用户可选择的表达候选，最终是否发送始终由用户决定。

## 2. 品牌

- 中文名：言和
- 英文名：Sway
- 推荐展示名：言和输入法 / Sway Keyboard
- Slogan：把话说得更好听，也更像你。
- 英文 Slogan：Say it better, stay yourself.

## 3. 目标用户

第一版聚焦有高频聊天压力、希望提升表达质量的用户：

- 亲密或暧昧关系中不知道如何接话、推进关系或保持边界的用户。
- 社交破冰、初次认识、回复动态时容易冷场的用户。
- 冲突修复、道歉、解释、拒绝、安抚场景中希望表达得体的用户。

第一版不建议泛化为全场景写作工具，也不建议直接扩展到职场公文、长文创作或恋爱导师长对话。

## 4. 核心场景

### 4.1 改写当前输入

用户先输入一句草稿，Sway 给出 3 条候选，例如：

- 更温柔
- 更幽默
- 更真诚

用户点击候选后插入到当前输入框，再自行确认是否发送。

### 4.2 根据对方消息生成回复

用户主动复制、粘贴或在主 App 中导入对方消息，Sway 生成 3 条回复候选，例如：

- 安全回复
- 高情商回复
- 推进关系回复

### 4.3 语气调节

用固定按钮降低 prompt 使用门槛：

- 甜一点
- 松弛一点
- 短一点
- 主动一点
- 克制一点
- 道歉
- 拒绝

### 4.4 收藏常用模板

用户可以收藏满意的候选，形成“我的话术”资产。后续可以在主 App 中管理收藏、分类和个人风格。

## 5. MVP 功能范围

### 5.1 主 App

- 新手引导与产品说明。
- 输入或粘贴聊天上下文。
- 选择场景、语气和长度。
- 生成 3 条候选回复。
- 复制候选到聊天 App。
- 收藏常用回复。
- 隐私设置与数据保存策略说明。
- 输入法安装与完全访问权限引导。
- 会员或额度入口预留。

### 5.2 iOS Keyboard Extension

- 改写当前输入框草稿。
- 手动粘贴对方消息后生成回复。
- 选择语气。
- 展示 3 条短候选。
- 点击候选插入文本。
- Full Access 未开启时，引导到主 App 兜底流程。

### 5.3 后端 AI 服务

- 场景化生成接口。
- 模型路由与 Prompt 编排。
- 内容安全策略。
- 额度、限流和成本统计。
- 默认不保存原始聊天内容。

## 6. 非目标

第一版明确不做：

- 自动读取微信、QQ、Telegram 等聊天 App 的完整聊天记录。
- 自动监听屏幕内容或后台抓取消息。
- 自动发送消息。
- 越狱、Hook、私有 API 或绕过系统权限的实现。
- 恋爱导师式长对话陪聊。

## 7. 交互原则

- 候选短而自然，避免作文式回复。
- 每次优先给 3 条，减少选择负担。
- 用户必须主动确认候选，产品不自动发送。
- 结果要像真人表达，避免明显 AI 腔。
- 对高风险内容进行拒绝、降级或引导到健康表达。
- 无完全访问权限时，主 App 兜底流程仍可用。

## 8. 内容安全原则

以下场景应拒绝或改写为健康表达：

- 骚扰、威胁、跟踪。
- 操控、PUA、情感胁迫。
- 未成年人性暗示。
- 隐私套取。
- 自伤、自杀或危险行为诱导。
- 仇恨、歧视和违法内容。

## 9. 隐私原则

- 默认不保存原始聊天文本。
- 只处理用户主动提供的文本或图片。
- 不读取通讯录。
- 不自动读取剪贴板。
- 不承诺读取任何第三方聊天 App 的完整上下文。
- 如需用于质量优化，必须获得用户明确授权。

## 10. 商业化建议

- 免费版：每日有限次数，基础语气。
- 会员版：更高额度、高级语气、收藏模板、个人风格包。
- 后续可扩展：关系风格包、节日场景包、多语言场景。

## 11. MVP 验收标准

- 用户复制一条聊天消息后，能在 3 秒左右得到 3 条自然回复。
- 用户输入一句生硬草稿后，能得到明显更自然的 3 个版本。
- 候选可以一键复制或插入，但不会自动发送。
- 未开启 Full Access 时，主 App 内生成流程仍可用。
- 生成内容无明显 AI 腔、冒犯、操控或越界。
- 微信、短信、Telegram、WhatsApp、备忘录等常见输入场景完成基础兼容验证。

## 12. 里程碑

### P0：App 内 MVP

- 主 App 输入/粘贴生成。
- 后端生成 API。
- 基础 Prompt 与安全策略。
- 50-100 条真实 case 回归集。

### P1：输入法 MVP

- Keyboard Extension 接入。
- Full Access 联网生成。
- 改写、回复、插入候选。
- 无权限时跳转主 App 兜底。

### P2：商业化与反馈闭环

- 订阅与额度。
- 收藏模板。
- 用户反馈。
- 质量、延迟、成本监控。

### P3：体验增强

- 个性化语气。
- 本地模板降级。
- 多语言。
- A/B Prompt 优化。
